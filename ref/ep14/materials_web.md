# Commons 以外の素材の置き場（2026-09-24）

14本目＝セウォル号沈没（2014-04-16・珍島沖）。調査役 agentC。Commons は別の人が測ったので触っていない。

- 読み方：WebSearch／WebFetch／curl（UA `Mozilla/5.0`・Referer 付き）／yt-dlp（`-J`＝形式の一覧とメタデータだけ。**YouTube の本体は落としていない**）／ffprobe（直のファイルの見出しだけ）
- **画像は1枚も目で見ていない。** 「中身」は題名・説明文・キャプションから書いた。幅×高は Flickr・DVIDS の頁の数値、yt-dlp・ffprobe の実測
- 🔴 YouTube・ニュースタパの幅は「器（入れ物）の幅」。実効の幅（引き伸ばしかどうか）は下の §1-A-4 の1コマ試験だけ（推定）
- ログイン・会員登録・申請はしていない。DVIDS は curl に JS の検問（AWS WAF）を返したので、ブラウザで検問を通すことはせず、WebFetch で読めた頁だけ使った
- 生データ・道具＝`scratchpad/agentC/`（`ytmeta.py` `ytsearch.py` `flsearch.py` `nt_probe.py` `calib.py` `nt_still.py`、結果 `*_out*.txt` `fl_*.txt` `cdx_*.txt`）。取り出した1コマ（PNG）は `scratchpad/agentC/frames/`（開いていない）

1. **事故そのもの（傾く船・救助）の動く記録映像で、幅1280以上かつ権利が明確に「使える」ものは 0本。** 幅1280以上（器の幅）の事故映像は6系統＝海洋警察の123艇の携帯電話（1920×1080）・ヘリ511号／512号（1920×1080）・513号／505号（1440×1080）と、全南漁業指導船201号のヘルメットカメラ（1920×1080）。測ったのはニュースタパの写し（© KCIJ）。どれも公共ヌリ（KOGL）の表示が無く、海洋警察庁の方針では「表示の無い資料は事前に協議して許可」＝**許可が要る側**。原本の置き場は見つからない：公式 YouTube（全1,024本・最古2017-09）にも、いまの公式サイトの報道資料（最古 2017-07-27）にも、2014年の公式サイトの記録（Wayback）にも無い。2014年は報道向けウェブハードで配布【二次】

**§1-A-4 実効の幅の試験（推定・目では見ていない）**

- 方法：ニュースタパの動画の中ほどの1コマを取り、「幅1280に縮めて戻す」往復で失う量（PSNR）を測る。同じコマを**わざと1280から引き伸ばし＋JPEG 圧縮した対照**と比べ、実物のほうが低ければ「1280より細かい中身がある」とみなす（`calib.py`）
- 123艇の動画4コマ（093950・094118・102859・103023）：実物 44.8／38.2／44.9／51.7 dB ＜ 対照 48.8／45.3／49.0／53.8 dB（差 2.1〜7.1 dB）＝**4コマとも1280より細かい中身あり → 原本の実効の幅は1280を超える見込み【推定】**
- ⚠️ 静止画だった10秒の項目（093107）は試験から外した（写真なので動画の画質を表さない）
