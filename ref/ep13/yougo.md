## 貼る本文（ここから下をそのまま概要欄へ）

【この動画に出てくる言葉】

・貨物ドア … 旅客機の床の下にある、荷物を入れる部屋（貨物室）のドア。DC-10には3つあり、この事故で外れたのは後ろの左側のドア
・与圧 … 高い空を飛ぶあいだ、機内の空気の圧力を外より高く保っておくこと。その圧力の差は、ドアを外へ押し出す力になる
・減圧 … 機内の空気が一気に抜けること。この事故では、ドアが外れて貨物室の空気が抜け、客室の床の上と下に圧力の差が生まれた
・フック … 貨物ドアの下の縁にある4つの金具。胴体の側に引っかかって、ドアを留める
・ロックピン … フックの後ろに差しこんで、フックが戻らないよう止めるピン
・通気扉 … 貨物ドアについた小さな扉。錠がかかっていなければ開いたままになり、機内に空気を詰められない。安全のための仕かけ
・のぞき窓 … 貨物ドアの下にある小さな窓。錠がかかると差しこまれる中のピンを、外から確かめるためのもの
・航空機関士 … 操縦室で、エンジンや電気を受けもつ乗員
・SB（サービス・ブレティン） … メーカーが航空会社へ出す、直し方の知らせ。すすめるものであって、命令ではない
・AD（耐空性改善命令） … FAAが出す「直さなければ飛んではならない」という命令。期限までに直さない機体は、飛ぶことができなくなる
・FAA（連邦航空局） … アメリカで旅客機の安全を受けもつ役所
・NTSB（国家運輸安全委員会） … アメリカで事故の原因を調べる国の機関
・紳士協定 … 書面ではなく、互いを信じて交わす約束
・上院 … アメリカの議会は2つに分かれていて、その片方。この動画の「上院の委員会」は、事故の3か月後に、調べた結果を報告にまとめた
・公聴会 … 議会が、関係する人を呼んで話を聞く会
・官報 … 国が決まりごとを広く知らせるために出す、公の刊行物。アメリカでは、貨物ドアの命令がここに載った日から、だれにでも効力を持った
・供述 … 調べに対して話した内容
・ボイスレコーダー … 操縦室の声や音を録る装置
・昇降舵 … 機首を上げ下げする、尾翼の舵
・確定の注文 … 取り消さない前提で出す注文

※ この動画の時刻は、パリの時刻です。事故の報告書は「世界時」（世界の基準の時刻）で書かれていて、パリの時刻はそれに1時間足したものです。
