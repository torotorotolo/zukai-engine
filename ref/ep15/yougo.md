## 貼る本文（ここから下をそのまま概要欄へ）

【この動画に出てくる言葉】

・NTSB … アメリカの国家運輸安全委員会。事故を調べ、原因を明らかにする国の機関
・無制限クラス … リノ・エアレースの6つの部門の1つ。プロペラ機を改造して走る。事故機はこの部門に出ていた
・パイロン … コースの目印の柱。リノのコースには10本あった
・ショーライン … 観客席とコースの境目の線。リノでは滑走路の南の端の線
・FAA … アメリカ連邦航空局。この大会を許可した
・テレメトリー … 機体の状態を地上へ送る装置
・トリムタブ … 機首を上げ下げする舵（昇降舵）の後ろの、小さな板。操縦桿を押さえ続けなくても、機首の向きを保てるようにする
・リンク … トリムタブの角度を決める細い棒
・補助翼 … 機体の傾きを操る舵
・G（ジー） … 体にかかる力を、体重の何倍かで表したもの。17.3Gは体重の17倍あまり
・後方乱気流 … 前を行く飛行機が残す空気の渦
・特別耐空証明 … 決められた目的と条件のもとで飛べる、という許可。事故機の許可は、レースと展示のために飛べるという中身だった
・冗長性 … 片方が壊れても、もう片方が残るようにする備え
・ゆるみ止めのナット（ロックナット） … 内側の繊維の詰め物で、ねじを締めつけるナット
・金属疲労 … 小さな力を何度もかけるうちに、金属にひびが育つこと
・フラッター … 機体の揺れと空気の力がかみ合って、速く震え続ける現象。速いほど、支えのかたさが落ちるほど起きやすい
・推定原因 … NTSB が調べた結果、事故の原因と判断したもの（報告書のまとめ）
・多数傷病者事故 … けが人が多すぎて、ふだんのやり方では追いつかない事故
・机上訓練 … 集まって話し合いながら、大事故の対応を確かめる訓練
・命令と通達 … FAA のエアレースの手引き2つ。命令（Order 8900.1）と、助言の文書の通達（Advisory Circular 91-45C）。ショーラインから観客席までの距離の数が食い違っていた。通達は直されないまま、2020年11月3日に廃止された
・安全勧告 … NTSB が「同じ事故を防ぐために、こう変えてほしい」と関係先に出す正式な求め。この事故のあと、10件が出された
