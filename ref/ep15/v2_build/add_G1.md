## ほかに④'が見る所（G1 の節の外）
- §1-11 の 6-2「（「水平に」「500フィート」は前の行）」＝第2版の `c210` の前の行は「FAAの条件は、水平の距離で決まっていた。」＝500フィートは語りに無い（`c818` の括弧で出る）。§2 の意味の照合 #2「「水平に」は前の行」も「「水平の距離」は前の行」
- 第1章の頭の計画の表（`c104` の行「報告書の表では機首上げと最大Gが先」）は台本の本文の中＝v2_sect の対象外。直すなら「報告書では」
- `c817`「第2章の終わりで触れた、FAAの別の資料。」（G7-11 の後半・G6 の担当）＝`c213` は第2版で「それは、あとの章で。」
- `c312`（G2-06）で「ホームパイロン」を噛み砕くなら、`c204` に合わせて「塔」でなく「柱」「目印」
- `c616`（G4-17）の「ゴールドは c214 で説明ずみ」＝`c214` は「ゴールド」と呼ばれる組、とだけ言う（いちばん上の組とは原文に無い＝G7-12 不採用）
- mech15 §2 が `c206` の出典欄「一般の事実（…）」を「文書名で始まらない札」に数える（決めどおりの直し）
