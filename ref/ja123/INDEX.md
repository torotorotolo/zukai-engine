# 日本航空123便　報告書から取り出した素材　台帳

**168枚。`python tools/extract_photos.py` が事故調査報告書の分割PDFから機械的に切り出した。**
名前は報告書の番号そのもの。`p043.jpg` は 写真‐43、`f012.jpg` は 付図‐12、
`a1f003.jpg` は 別添1 付図‐3。

## 出どころ

| | |
|---|---|
| 資料 | 航空事故調査報告書 **62-2**（日本航空 JA8119・昭和62年6月19日） |
| 版 | 🔴 **日本語版の分割PDF**（`jtsb.mlit.go.jp/aircraft/download/62-2-JA8119-NN.pdf` の 01〜11）。一覧は `jtsb.mlit.go.jp/jtsb/aircraft/download/bunkatsu.html` から辿る |
| 権利 | 運輸安全委員会 **公共データ利用規約 PDL1.0**（`jtsb.mlit.go.jp/cyo.html`）。複製・**公衆送信**・翻案を許諾、CC BY 4.0 互換 |
| 条件 | 「出典：〇〇ウェブサイト（URL）」の明示と、**加工した旨**の記載 |
| 画面表記 | `出典：運輸安全委員会 航空事故調査報告書 62-2（JA8119）／写真-N` |

⚠️ **英語版（`mlit.go.jp/jtsb/eng-air_report/JA8119.pdf`）を使ってはいけない。**
約150dpi・2値で、写真1枚あたり 470×650px 相当しかない。日本語版は約400dpi。

⚠️ `62-2-JA8119.pdf` を直に叩くと**表紙1枚（84KB）しか返らない**。分割版を落とす。

## 🔴 加工の内容（PDL1.0 が求める「加工した旨」）

1. ページから写真・図の矩形だけを切り出した
2. **長辺 1200px へ縮小し、ぼかし 0.7 をかけた**
   原本は **bpc=1（2値・JBIG2）** で中間調が1階調も無く、濃淡はすべて誤差拡散ディザ。
   1920px へ伸ばすと**砂目がそのまま出て写真として読めない**（実写して確認）。
   縮小＋わずかなぼかしでディザが階調に戻る。
3. 報告書のキャプション文字が切り出しの縁に残らないよう、文字の帯を外した

   （表は罫線と文字で描かれていて、画像としては1枚も入っていない）

3. 切る矩形は `page.get_drawings()` の外接で実測し、**すぐ下の本文が入らないところまで詰めた**
