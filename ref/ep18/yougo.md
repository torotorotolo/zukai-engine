## 貼る本文（ここから下をそのまま概要欄へ）

【この動画に出てくる言葉】

・査問会 … 海軍が事故の事実を調べるために開く会。事実を「認定」、判断を「意見」、改めるべきことを「勧告」としてまとめる
・試験深度 … その艦がふだん潜ってよいと決められた、いちばん深い所。スレッシャーの数は今も伏せられている
・公聴会 … アメリカ議会の、原子力を受け持つ委員会（両院原子力合同委員会）が、人を呼んで話を聞いた会。1963年と64年に開き、記録は1965年に印刷された
・艦船局 … 艦を設計した海軍の部署
・水中電話 … 水の中を、音で声を伝える電話
・救難艦・救難室 … 沈んだ潜水艦から乗員を助けるための船と、乗員を助け出すための部屋
・内破 … 外の水の力で押しつぶされること
・銀ろう付けの継手 … 銀を含む金属を溶かしてすき間に流しこみ、管どうしをくっつけた所
・超音波の検査 … 継手に外から音を当て、金属がどれだけしっかり付いているかを調べる検査
・タンクを吹く … 主タンクの海水を圧縮した空気で押し出し、艦を軽くして浮き上がること
・減圧弁・こし器 … 空気の圧力を下げる弁と、その弁に付いた、ごみをこす金網
・海の音の監視 … 海の中の音を遠くから聞き取る、海軍の監視の仕組み
・情報公開の法律 … アメリカの情報公開法（FOIA）。国の記録を、求めに応じて公開させるための法律
・塗った理由を示す札 … 公開された記録の、塗りつぶした所に付いている記号。b(1)＝国の安全、b(3)＝法律で伏せてよいと決められた情報、b(6)＝個人の私生活
・トリエステ … 深い海へ潜る潜水艇。人が乗り込む部屋（ゴンドラ）が付いている
・サブセーフ … 事故のあと始まった、潜水艦の安全の取り組み。安全の改修を終えて艦船局が1隻ずつ認めるまで、深さの制限が続いた
