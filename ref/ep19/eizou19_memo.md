## §5 共通の棚 `ref/stock/` の設計の芯（ノートは `stock_shelf_design.md`）
- 台帳 `ref/stock/stock.json` だけを git に入れる（`git add -f`）。**動画そのもの（mp4）と控えの静止画は入れない**＝Pexels・Pixabay の許諾は「素材を単独で配る」ことを禁じる（公開リポに置く＝配る）。焼くときは Actions が台帳の `media` から落として md5 で確かめる（`footage.fetch` と同じ）
- 鍵＝`px_<Pexels の番号>`／`pb_<Pixabay の番号>`（サイトの番号は変わらない・2サイトで番号がぶつからない）。中身の言葉は `what` に
- 回ごとの使い方は `ref/epNN/clips.json`（`"stock": true`・`"stock_id"`・区間）に書き、棚の `used_in` に回とカットと区間を足す
- 回をまたいで使うとき：字と顔は**区間ごと**に焼いて確かめる（確かめた区間を `ok_ranges` に）・時代と型は回ごとに判断・「イメージ」と出典の行は毎回・申し立てが来たら `claims` に書いて以後使わない
- 棚に書くのは本線に push するチャットだけ（1度に1本）
