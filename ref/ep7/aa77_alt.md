## 3. 図に渡す点（`graph`・y はメートル）

🔴 **8:20〜8:46 の上昇は描かない。**原文は両端の2点しか言っていないので、
線を引くと**間を自分で作る**ことになる（[[feedback-charts-lie-with-their-defaults]]）。
**8:46（巡航に届いた時刻）から始める。**

x ＝ 8時を0とした分（`xticks` で 8:46 / 9:00 / 9:20 / 9:37 と出す）。

```
pts = [(46, 10668), (55, 10668), (60, 10668), (62, 10668),
       (67,  7620), (68,  7620), (69.5, 6706), (71, 7696),
       (82,  7696), (89,  2134), (91,  2438), (93, 2073),
       (94,  2134), (96,   610), (97.75,  0)]
```

- 1 ft ＝ 0.3048 m で換算（35,000→10,668／25,000→7,620／22,000→6,706／25,250→7,696／
  7,000→2,134／8,000→2,438／6,800→2,073／2,000→610）
- 🔴 **9:00〜9:07 と 9:22〜9:29 のあいだの形は、原文が言っていない。**
  原文は「降り始めた時刻」と「水平になった時刻・高度」だけを言うので、
  **その2点を直線でつなぐ**。図の `note` に「点は原文が言っている時刻と高度だけ」と書く。
