### 🔴 なぜこの並びか

①が挙げた強みは「**崩れる前に、分かっていた**」こと。だから**当日の朝（`c1`）を先に置いて**、
「なぜ客は外に出されなかったのか」を最初の5分で立てる。
原因（`c3`〜`c5`）はそのあとに置き、**`c6` で当日の午後に戻って答え合わせをする**。

- `c1` と `c6` は**同じ1日の前半と後半**。挟んだ `c2`〜`c5` が「なぜ壊れる建物になったのか」。
  この形にすると、`c6` の「すぐには崩れない」という診断が、**視聴者にだけ意味が分かる**
- `c5` を最長（22カット）にする。**柱と床の話が分からないと、この事故は「運が悪かった」で終わる**
- `c7` を16カットと短くする。**崩壊そのものは20秒。引き延ばさない**（→[[feedback-reduce-dont-slow-down]]）
- 🔴 `c8` を置く理由＝**「502人が亡くなった」で終わらせない。**17日目に生きて出てきた人がいる
- `ep` は「会長が捕まった」で終わらせず、**法律が変わったこと**まで出す

## 4. ③尺をこう決めた

### 4-1. 35分にした理由

| 物差し | 数字 | 効き方 |
|---|---|---|
| ch の既定値 | 27〜40分（`check_script.py`） | 35分は内側 |
| 実測の勝ち帯 | **35〜50分が1.47倍** | 35分は帯の下端ぴったり |
| 三豊の競合（①の実測） | **32分 → 1,035,309回**（近所比3.57×）／17分 → 85,378回（0.80×） | 当たった回のすぐ上 |
| 🔴 Sho の話速が暫定 | 比から出した 6.12字/秒。7本目は同じやり方で **7.1%** 外れた | **35分 ×1.071＝37.5分**＝上限40分の内側。36分だと38.5分で余裕が2割減る |

→ **35分。**⚠️ 40分に寄せない理由＝**分かりやすさが最優先**（情報を尺で薄めない）。
⚠️ 34分に詰めない理由＝`c3`〜`c5`（なぜ壊れる建物になったか）を削ると、
**「手抜き工事だった」の一言で終わってしまい、当日の朝の前兆が効かなくなる**。

### 4-2. 文字/秒は **6.12（Sho・暫定）**。⑤a で取り直す

`check_script.py` の `CPS_FALLBACK=6.12` / `PER_CUT=10.74`（9本目⑥で Sho 用に入れた暫定値）。
出どころ＝8本目（Koichi・実測 6.622字/秒・10.047秒/カット）に、Sho と Koichi の比 **0.9247** を当てたもの。

**検算（この値で 35分が出るか）:**

```
声   11,040 ÷ 6.12                  = 1,803.9 秒
行間 GAP 0.40 ×(441−195)            =    98.4 秒
頭尻 (LEAD 0.35 + TAIL 0.50)× 195   =   165.8 秒
決め所 2.0 × 14                     =    28.0 秒
                            合計    = 2,096.1 秒 ＝ 34分56秒（目標 2,100秒と −0.19%）✅
```

- ⚠️ **暫定値。**⑤a で `audio/narration.json` ができたら `use_measured_cps` が本物に差し替える
- ⚠️ **±7% を見込む**＝32分30秒〜37分25秒。どちらに転んでも 27〜40分の内側
- 🔴 **共通エンディング（約10秒）は尺の門番に足す**（→ 記憶 `project-jiko-common-ending`）
