## 1. 貼る本文（`description` の【出典】の**前**に置く）

```
【この動画に出てくる言葉】
出てくる順に並べています。

・瑞草区（ソチョく） … ソウルを分ける区の一つ。百貨店があった場所。
・白書 … 役所が、ある出来事について調べたことをまとめて出す報告書。この動画が使うのは、ソウル市がまとめたもの。
・冷却塔 … 冷房に使う水を、外の空気で冷やす装置。この建物では屋上に置かれていた。
・竣工（しゅんこう） … 工事が全部終わること。そのあと役所の検査を受けて、はじめて正式に使えるようになる。
・延べ（のべ）… 広さで使うときは、建物の各階の床を全部たした数。人や車の数で使うときは、同じ人・同じ車を日ごとに数えなおして足した数で、実際にいた人数より多くなる。
・監理（かんり） … 工事が図面どおりに行われているかを見る役。図面を描く「設計」、実際に建てる「施工」とは別の役目。
・請負限度制（うけおいげんどせい） … 会社の規模に応じて、引き受けられる工事の額に上限をつける決まり。当時の韓国にあった。
・押えコンクリート … 屋上で、水が入らないようにする層（防水層）の上に、押さえとしてかぶせるコンクリート。
・梁（はり） … 柱と柱のあいだにわたす、横向きの太い棒。ふつうの鉄筋コンクリートの建物は、これで柱と柱をつなぐ。
・フラットスラブ … その梁を使わず、柱の上に厚い板を置いて、その上に床をじかに載せる作り。この建物がこれだった。
・せん断破壊 … 床が、柱のまわりの線に沿って抜け落ちる壊れ方。
・焼香所（しょうこうじょ） … 亡くなった人に線香をあげ、手を合わせるために設けられる場所。
・国政監査（こくせいかんさ） … 韓国の国会が、決まった時期に役所の仕事を調べる仕組み。
・禁錮（きんこ） … 刑務所に入れる刑のうち、作業をさせないもの。作業をさせるほうが「懲役」。
・執行猶予 … 刑を言い渡したうえで、決められた期間なにも起こさなければ、その刑を受けなくてよいとする仕組み。
・業務上過失致死傷 … 仕事のうえで必要な注意を怠り、人を死なせたりけがをさせたりした罪。
・共同正犯 … 複数の人がひとつの罪を一緒に犯したとして、全員を主犯として扱うこと。
```
