## 1. 尺を 36分30秒 にした根拠

### 1-1. 尺帯ごとの近所比（母集団 `ref/themes/pool.json`・**N=1,813**・このチャットで再現）

| 尺帯 | 本数 | 再生 中央値 | **近所比 中央** | 1.0超 |
|---|---:|---:|---:|---:|
| 25-30分 | 272 | 27,034 | 1.02 | 51% |
| 30-35分 | 163 | 52,052 | 1.08 | 53% |
| 🔴 **35-40分** | **86** | **61,912** | **1.33** | **66%** |
| 40-50分 | 57 | 53,530 | 1.13 | — |
| 50分超 | 26 | 60,500 | 1.94 | — |

### 1-2. 並べ替え検定（20,000回・`ref/ep11/dur_test.py`・`seed=20260921`）

| | p |
|---|---:|
| 陰性対照（25-30分を無作為に半分に割る） | 0.1211（有意でない＝道具は何にでも有意と言わない） |
| 陽性対照（50分超 vs 15分未満） | 0.0006 ← 有意 |
| **35-40分 vs 25-30分** | **0.0071 ← 有意** |
| **35-40分 vs 30-35分** | **0.0235 ← 有意** |
| 30-35分 vs 25-30分 | 0.2695（有意でない） |

### 1-3. 🔴 「50分超のほうが高い」をそのまま採らなかった理由

再現したとき **50分超（N=26）の近所比が 1.94** で 35-40分（1.33）より高く、
**検定も 50分超 vs 35-40分 で p=0.0095（有意）**と出た。**それでも 36分30秒 にする。**

1. **単調ではない。**あいだの **40-50分（N=57）は 1.13** で、
   **35-40分に対して p=0.8912＝むしろ低い**。「長いほど強い」なら 40-50分が間に入るはずで、入っていない。
   **40分超をひとまとめにしても 1.216（p=0.6581・有意でない）。**
2. **中身が別の作り方の動画。**50分超の上位は
   **96.3分（近所比 38.58）・118.1分（7.14）・80.2分（4.91）・76.0分（3.86）**＝
   **60分を超える総集編・大特集**。27〜40分の回とは商品が違う。
3. **N=26 で、上位数本が中央値を持ち上げている。**
4. ch の決め＝**27〜40分**（`check_script.DUR_MAX_DEFAULT`）。**動かすのはカズヤくんの判断**で、
   ③が数字だけで越える場所ではない。

### 1-4. この題材の棚（核・放射線の65本）でも 35-40分が最良

| 尺帯 | N | 近所比 中央 | 1.0超 |
|---|---:|---:|---:|
| 0-20分 | 12 | 0.79 | 17% |
| 20-25分 | 11 | 1.51 | 73% |
| 25-30分 | 17 | 1.26 | 59% |
| 30-35分 | 9 | 1.21 | 56% |
| 🔴 **35-40分** | **7** | **1.57** | **86%** |
| 40-50分 | 8 | 1.14 | 62% |

⚠️ 20-25分の 1.51 は **N=11 の短い解説もの**で、この ch の作りではない。
棚の上位2本（**38.7分＝近所比6.90／39.6分＝3.93**）はどちらも 35-40分。

### 1-5. なぜ 36分30秒 で、38分や39分ではないか
- 上限40分は門番の **E**。**38分以上に置くと、④で1章ふくらんだだけで落ちる。**
- 11本目（36分21.5秒）・5本目 SL-1（36分21秒）が**同じ帯の中で実際に通っている**。
- 35-40分の帯の**真ん中より少し下**＝いちばん外しにくい。

## 2. 尺の検算（④の門番と同じ式）

```
尺 = 本文字数/CPS + GAP×(行数−カット数) + (LEAD+TAIL)×カット数 + 2.0×決め所数
   = 11,190/5.885 + 0.40×(428−190) + 0.85×190 + 2.0×16
   = 1901.4 + 95.2 + 161.5 + 32.0 = 2190.1秒 = 36分30秒 ✅
```

### 2-1. 🔴 式そのものの陽性対照（このチャットで回した）
```
python tools/check_script.py --refcheck
  ✓ 4本目 サーフサイド  予測 2128.2 / 実測 2127.3 → +0.04%
  ✓ 5本目 SL-1        予測 2181.2 / 実測 2181.3 → −0.01%
  ✓ 7本目 9.11        予測 1966.7 / 実測 1966.8 → −0.01%
  ✓ 8本目 コロンビア号   予測 2168.4 / 実測 2166.0 → +0.11%
```
**4本とも ±0.11% 以内＝式は生きている。**

### 2-2. 🔴 文字/秒についての申し送り（④'と⑤aへ）
`CPS_FALLBACK = 5.885` は **10本目の完成音の実測**（11,580字 ÷ 発話 1,967.700秒）。
⚠️ **この回の声と TEMPO が決まったら、⑤a で `use_measured_cps` に差し替える。**
⚠️ **読み辞書が厚い回ほど CPS は低く出る**（字幕の字数で割るため）。
この回は**数字が多い**（15メガトン・6メガトン・1,423隻・23名・2.5倍・160km…）ので、
🔴 **かな固定を入れると字数が増えて尺が伸びる。**④は**11,190字を上限として書く**。
→ `feedback-tts-misreads-are-positional`（数字は聞取で検証できない＝先回りしてかな固定）
