### 🔴 なぜこの並びか

①が挙げた強みは「**共感の入口が2つある**」こと＝
「小さな破片だから大丈夫だろう」と確認しなかったこと／技術者が3回求めたのに断られたこと。
**この2つを中盤（c5・c6）に置いて、動画の谷になりやすい 15〜23分をいちばん強い材料で埋める。**

- `c2`〜`c3` は**同じ0.2秒を2回描く**。1回目は「誰も気づかない」、2回目は「フィルムに写っていた」。
  同じ出来事を視点を変えて2度出すので、同型の反復にはならない。
- `c5` の直後に `c6` を置く。「断られた」で終わらせず、**「では助かったのか」に必ず答える**。
  ここを分けないと、視聴者が一番知りたい問いが c9 の後ろまで来ない。
- `c7` を30カットと最長にする。**この回で唯一、動く映像が主役になる章**（§3）。

## 4. ③尺をこう決めた

### 4-1. 35分にした理由

| 物差し | 数字 | 効き方 |
|---|---|---|
| ch の既定値 | 27〜40分（`check_script.py`） | 35分は内側 |
| 実測の勝ち帯 | **35〜50分が1.47倍** | 35分は帯の入口。**27〜35分は帯の外** |
| コロンビア号の競合 | **34分32秒 → 197,769回**（次は22分19秒 → 73,978回） | 当たった回のすぐ上 |
| 母集団の宇宙もの32本 | 27〜40分帯21本が中央 53,294回（それ以外の2.90倍） | |
| 7本目（9.11）の実績 | 32分47秒 | 今回は素材が厚いので少し長く取れる |

→ **「ch の上限40分」と「実測の勝ち帯35〜50分」が重なるのは 35〜40分。その入口を採る。**
⚠️ 40分に寄せない理由＝**分かりやすさが最優先**で、情報過多を尺で薄めない
（[[feedback-reduce-dont-slow-down]]）。素材が厚いからといって伸ばすのは逆。

### 4-2. 🔴 文字/秒を7本目から取り直した（6.17 → **6.688**）

回ごとに取り直す規則（[[feedback-per-episode-constants-go-stale]]）。
7本目が焼き上がったので、**推定値ではなく完成した回から採れる**ようになった。

**2通りの別の道から同じ値が出た（開き 0.00%＝陽性対照）:**

| 道 | 計算 | 結果 |
|---|---|---|
| ① 完成尺から引く | 1,966.833秒 −（行間 0.40×(454−202) ＋ 頭尻 0.85×202 ＋ 決め所 2.0×13）= 声 1,668.3秒<br>11,157字 ÷ 1,668.3 | **6.688** |
| ② 音から直接 | `audio/narration.json` の字幕の長さ（`d`）の総和 1,668.3秒 → 11,157 ÷ 1,668.3 | **6.688** |

- ⚠️ **決め所の数は台本の `★` ではなく `cuts.SPEC` の図の型 `quote` を数える**（7本目＝**13**）。
  `narration.py` の `SCRIPT` には行頭の `★` が無く、`check_script.py` の `STAR_RE` では 0 と出る。
- 旧の 6.17 は「5本目の 5.642 に声の比 1.1485 を当てた」推定で、7本目に当てると
  **2,106.8秒（実測 1,966.8秒・+7.11%）**と外れていた。
- ✅ `check_script.py --refcheck` は **3本とも 0.5% 以内**
  （4本目 +0.04% ／ 5本目 −0.01% ／ 7本目 −0.01%）。
- ⚠️ **これは Koichi・TEMPO 1.0 の値。**声か TEMPO を替えたら無効。
  ⑤a で `narration.json` ができたら `use_measured_cps` が本物に差し替える。
