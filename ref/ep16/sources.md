## 3. 使わない言い方（④'で機械的に拾う）

| 言い方 | なぜ | 代わり |
|---|---|---|
| 「ダムが**決壊**した／崩壊した」 | S1 PDF171「耐えた」・PDF98「ダムを越えて」 | 「水がダムの上を越えた（越流）」 |
| 「**M字**の亀裂」 | S1 にも S8 にも無い（二次の言い方） | 「長さ約2.5キロの亀裂」 |
| 「**世界一**のアーチダム」 | S8＝ヨーロッパで最も高い二重アーチダム／少数派1だけが「世界一」 | 「当時ヨーロッパで最も高いアーチダム（学術の総説）」 |
| 「天端から**250m**の波」・「犠牲者**2,500人**」 | 英語の解説記事（Petley 2008）・当時の新聞だけ | §2-6・§2-9 の形 |
| 「崩落は**100秒**」 | 100秒は速さが跳ね上がるまでの時間（PDF147） | 「1分足らず（45秒未満＝学術）」 |
| 「**ポンテセイ**の崩落（1959）を議会が警告に挙げた」 | S1 に Pontesei の記述なし（抽） | 出すなら S9・S8 の出典で |
| 「**国有化の前に高く売るため**湛水を急いだ」 | 多数派は否定（PDF176（抽））・裁判でも根拠なし（Wikipedia＝三次） | 言わない（噂として扱うなら §B2-6 の札つき） |
| 「**Toc＝腐った**」 | 典拠なし（①） | 言わない |
| 「メルリンが**トックの危険**を書いて起訴された」 | 起訴の記事（1959）はエルト村の話・無罪は1960-11-30 | 「村の危険を書いて訴えられ、無罪。トックの大きな塊を書いたのは無罪のあと」 |
