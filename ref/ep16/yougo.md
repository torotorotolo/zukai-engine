・議会の調査委員会 … イタリアの上院と下院の議員でつくった、この災害の調査の委員会。1965年に最終報告をまとめた（反対意見の報告2本も入れて248ページ）
・越流（えつりゅう） … 水がダムの上を越えて流れること。ダムそのものが壊れる「決壊」とは違う

・アーチダム … 弓のように曲げた薄い壁で、水の力を、谷の両側の岩へ逃がすダム
・二重のアーチ … 横にも縦にも曲がった、アーチダムの形
・学術の総説 … 研究をまとめた論文。この動画では、2005年の Genevois と Ghirotti の論文「The 1963 Vaiont Landslide」
・天端（てんば） … ダムのいちばん上の部分。このダムでは標高725.5メートル
・公社 … 国がつくり、国じゅうの電気の事業をまとめる会社。ここでは、1962年12月に法律でつくられたエネル
・地質学者 … 岩や地層のなりたちを調べる専門家

・多数派・少数派 … 議会の調査委員会で、多数決で通った本文が多数派（賛成19・反対8）。反対した議員の報告が少数派で、2本とも最終報告に添えて出された
・ダムを検査する国の委員 … ダムが決まりどおりに造られ、水をためたり抜いたりしても問題がないかを確かめる、国の委員会の委員
・水理模型 … 本物を小さくした模型に水を流して、水の動きを確かめる道具。この谷は、200分の1の大きさで再現された
・土木局 … 国の公共事業の役所の、県ごとの出先（ジェニオ・チヴィレ）
・憲兵隊 … 軍に属する警察（カラビニエリ）

・予審 … 裁判を開くかどうかを、判事が調べて決める手続き（当時のイタリア）
・破毀院（はきいん） … イタリアの最高裁判所
・恩赦 … 国の決まりで、刑の一部を免除すること
・世界の記憶 … 世界に残す価値のある記録を選んで登録する、ユネスコのしくみ。2023年、この災害の裁判の記録が登録された
